# Diccionario de datos

id   Número (Number) Identificador único de cada registro de venta.
fecha   Texto (String) Fecha en que se realizó la venta, representada en formato AAAA-MM-DD.
cliente  Texto (String) Código identificador del cliente que realizó la compra.
producto   Texto (String) Nombre del producto vendido.
ciudad   Texto (String) Ciudad asociada al cliente o a la venta.
cantidad   Número (Number) Número de unidades vendidas del producto en la transacción.
precio   Número (Number) Precio unitario del producto en pesos colombianos.
